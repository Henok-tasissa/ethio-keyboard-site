Made for typing Amharic every day

Works in any app: Messages, Mail, Notes, Safari, Chrome, Word, Slack and more.

⌨️

Phonetic typing

Type selam and press Space to get ሰላም. No new layout to learn, no key stickers.

🎛️

Fidel palette

See all seven vowel forms of the letter you are typing, with the key to press under each. Click or press 1–7 to change it.

💡

Smart suggestions

A built-in dictionary suggests words as you type. What you typed stays the default, so you are always in control.

፲

Geez numbers and punctuation

። ፣ ፤ ፥ ፧ and ፩ to ፼ with one shortcut each, or pick from the symbol palette.

🔒

Private and offline

Never connects to the internet. Nothing you type is stored, logged or sent anywhere. Password fields are left alone.

🌍

Switch languages fast

Press Control + Option + Space to type English without leaving the keyboard, and again to go back.

Press Tab to switch to the letter you meant

Amharic has letters that sound the same, like ተ and ጠ. Type the sound, then press Tab while the letter is underlined to move to the next one. Shift + Tab goes back.

type t ተ press Tab ጠ press Tab ተ

Tab changes the last letter you typed. It also works on c: you get ክ, and Tab gives ች, so you do not have to type ch.

Set up in about two minutes

Full details are in the install guide.

Download and install

Open the disk image, drag Ethio Amharic for Mac to Applications, open it and press Install. The app walks you through the rest.

Add it in System Settings

Keyboard → Input Sources → Edit → +, choose Amharic, then Ethio Amharic Keyboard.

Pick it in the menu bar and type

Choose the keyboard from the input menu and type selam. If an app still types English, restart it.
